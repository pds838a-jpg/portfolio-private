## 実行方法

リポジトリをダウンロードし、各HTMLファイルをブラウザーで開きます。CSSは各ファイルのstyle要素にまとめているので、インストールやビルドは不要です。

저장소를 내려받고 HTML 파일을 브라우저로 엽니다. CSS가 파일의 style 요소에 들어 있어 설치나 빌드가 필요하지 않습니다.

03ではbox-sizing、06ではflex-directionを変えて表示を比較できます。05と07は画面の幅を変え、08と09はマウスとキーボードの操作を比較します。確認した結果や自分で変更した内容は、確認後に追記していきます。
