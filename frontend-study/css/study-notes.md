# HTMLの続きとCSSを復習

前回はHTMLの基本構造を整理したので、今回はその続きからCSSまでを復習してみようと思う。保存してある授業のファイルを見ながら、タグの使い方やページの見た目を変える方法をまとめておく。

지난번에는 HTML의 기본 구조를 정리했다. 이번에는 저장해 둔 수업 파일을 보면서 HTML의 나머지 내용과 CSS를 복습하려고 한다. 태그로 내용을 넣는 방법과 페이지의 모양을 바꾸는 방법을 함께 정리해 둔다.

## HTMLで内容を入れる

HTMLでは、内容に合わせてタグを選ぶ。見出しは`h1`〜`h6`、段落は`p`、順序のない一覧は`ul`、順序のある一覧は`ol`を使う。一覧の一つひとつの項目は`li`で囲む。

HTML에서는 내용에 맞게 태그를 고른다. 제목은 `h1`~`h6`, 문단은 `p`, 순서 없는 목록은 `ul`, 순서 있는 목록은 `ol`을 사용한다. 목록의 각 항목은 `li`로 감싼다.

```html
<h1>공부할 내용</h1>
<p>웹 페이지를 만드는 방법을 복습하고 있습니다.</p>
<ul>
  <li>HTML로 내용 넣기</li>
  <li>CSS로 모양 바꾸기</li>
</ul>
```

見出しの数字は、文字をどれくらい大きくするかではなく、内容の階層で考える。文字の大きさはCSSでも変えられる。`strong`は重要な内容、`em`は強調を表す。

제목의 숫자는 글자 크기보다 내용의 단계로 생각해야 한다. 글자 크기는 CSS로 바꿀 수 있다. `strong`은 중요한 내용, `em`은 강조를 나타낸다.

表は`table`の中に行の`tr`を書き、その中に見出しセルの`th`やデータセルの`td`を入れる。`rowspan`は行方向、`colspan`は列方向にセルをまとめるときに使う。

표는 `table` 안에 행인 `tr`을 쓰고, 그 안에 제목 셀인 `th`와 데이터 셀인 `td`를 넣는다. `rowspan`은 행 방향, `colspan`은 열 방향으로 셀을 합칠 때 사용한다.

ページ全体のまとまりには`header`、`nav`、`main`、`section`、`footer`なども使える。何でも`div`にするより、どんな役割の部分なのかを考えてタグを選んでおきたい。

페이지의 영역을 나눌 때는 `header`, `nav`, `main`, `section`, `footer` 등도 사용할 수 있다. 전부 `div`로 묶기보다 어떤 역할을 하는 부분인지 생각하면서 태그를 고르려고 한다.

## 画像とリンク、入力欄

画像は`img`、リンクは`a`で入れる。`src`は画像の場所、`href`はリンク先を指定する。画像の`alt`には、画像の内容や役割が伝わる文章を書く。装飾だけの画像なら空にできる。

이미지는 `img`, 링크는 `a`를 사용한다. `src`는 이미지 위치, `href`는 연결할 주소를 지정한다. `alt`에는 이미지의 내용이나 역할을 알 수 있는 문장을 쓴다. 장식용 이미지라면 비워 둘 수 있다.

```html
<img src="images/study.jpg" alt="책상 위에 펼쳐 놓은 HTML 교재">
<a href="review.html">복습 페이지 보기</a>
```

この例の`images/study.jpg`は、HTMLファイルから見た画像の場所になる。画像が表示されないときは、ファイル名だけでなくフォルダーの位置も確認する。音声や動画には`audio`や`video`を使い、`controls`を付けると再生操作が表示される。

여기서 `images/study.jpg`는 HTML 파일을 기준으로 한 이미지 위치다. 이미지가 나오지 않으면 파일 이름뿐 아니라 폴더 위치도 확인해야 한다. 소리와 영상에는 `audio`, `video`를 사용하고 `controls`를 넣으면 재생 조작 버튼이 표시된다.

入力フォームでは`form`、`input`、`select`、`textarea`などを使う。`input`は`type`によって文字入力、チェックボックス、ラジオボタンなどに変わる。

입력 폼에는 `form`, `input`, `select`, `textarea` 등을 사용한다. `input`은 `type`에 따라 문자 입력, 체크박스, 라디오 버튼 등으로 바뀐다.

```html
<label for="name">이름</label>
<input type="text" id="name" name="name" required>
```

`label`の`for`と`input`の`id`を同じにすると、ラベルと入力欄がつながる。`name`は送信するデータの項目名。`required`で必須入力にできるけれど、入力欄を作るだけでデータが保存されるわけではない。

`label`의 `for`와 `input`의 `id`를 같게 하면 라벨과 입력란이 연결된다. `name`은 전송할 데이터의 항목 이름이다. `required`로 필수 입력을 지정할 수 있지만, 입력란을 만들었다고 데이터까지 저장되는 것은 아니다.

## CSSで見た目を変える

HTMLで内容を入れたら、CSSで色や大きさ、余白などを指定する。基本の形は「セレクターに対して、プロパティと値を書く」と覚えておく。

HTML로 내용을 넣은 뒤 CSS로 색, 크기, 여백 등을 지정한다. 기본 형태는 ‘선택자에 속성과 값을 쓴다’고 기억해 두려고 한다.

```css
p {
  color: #333;
  font-size: 16px;
  line-height: 1.7;
}
```

この例では段落の文字色、大きさ、行間を指定している。文字の種類は`font-family`、太さは`font-weight`、配置は`text-align`で変えられる。

위 예제는 문단의 글자색, 크기, 줄 간격을 지정한다. 글꼴은 `font-family`, 굵기는 `font-weight`, 정렬은 `text-align`으로 바꿀 수 있다.

CSSはHTMLの`style`属性や`style`要素にも書ける。別のファイルにまとめる場合は、`head`の中で読み込む。

CSS는 HTML의 `style` 속성이나 `style` 요소 안에도 쓸 수 있다. 별도 파일로 정리할 때는 `head` 안에서 연결한다.

```html
<link rel="stylesheet" href="style.css">
```

セレクターには`p`のような要素名のほかに、`.クラス名`や`#ID名`がある。複数の指定が重なったときは、いつでも最後の指定が勝つわけではない。同じ出所・レイヤー・重要度などの条件なら、詳細度が高い指定が優先され、詳細度も同じなら後の指定が使われる。

선택자는 `p` 같은 요소 이름 외에도 `.클래스명`, `#ID명`이 있다. 여러 지정이 겹친다고 항상 마지막 지정이 적용되지는 않는다. 출처·레이어·중요도 등의 조건이 같으면 명시도가 높은 지정이 우선하고, 명시도도 같으면 나중 지정이 적용된다.

親の文字色などを子が引き継ぐこともある。ただし、余白や幅まで全部引き継ぐわけではない。CSSが思ったように反映されないときは、クラス名や読み込み先と、どの指定が実際に使われているかを確認したい。

부모의 글자색 등을 자식이 물려받기도 한다. 그렇다고 여백이나 너비까지 모두 상속되는 것은 아니다. CSS가 생각대로 적용되지 않을 때는 클래스 이름과 연결 경로, 실제로 적용된 지정을 확인하려고 한다.

## paddingとmarginを分けて覚える

要素の箱は、内容、内側の余白、枠線、外側の余白に分けて考える。`padding`は内容と枠線の間、`margin`は枠線の外側。

요소의 박스는 내용, 안쪽 여백, 테두리, 바깥쪽 여백으로 나누어 생각한다. `padding`은 내용과 테두리 사이, `margin`은 테두리 바깥이다.

```css
.card {
  width: 200px;
  padding: 20px;
  border: 2px solid #ccc;
  margin: 16px;
  box-sizing: border-box;
}
```

`box-sizing: border-box`なら、200pxの中にpaddingとborderを含める。`content-box`なら内容だけが200pxになり、この例では枠までの幅が244pxになる。marginはどちらの場合も幅に含まれない。

`box-sizing: border-box`이면 200px 안에 padding과 border가 포함된다. `content-box`라면 내용만 200px이므로 위 예제에서 테두리까지의 너비는 244px이다. margin은 어느 경우에도 너비에 포함되지 않는다.

角を丸くするには`border-radius`、影には`box-shadow`を使う。背景の色や画像は`background`関連のプロパティで指定でき、グラデーションも使える。背景画像の`cover`は領域を埋めるので一部が切れることがあり、`contain`は画像全体が収まる代わりに余白ができることがある。

모서리는 `border-radius`, 그림자는 `box-shadow`로 지정한다. 배경색과 이미지는 `background` 관련 속성으로 설정하고 그라데이션도 사용할 수 있다. 배경 이미지의 `cover`는 영역을 채우므로 일부가 잘릴 수 있고, `contain`은 이미지 전체를 넣는 대신 여백이 생길 수 있다.

## 要素を並べる

`display`で表示や並べ方を変えられる。位置を指定する`position`では、`relative`は元の位置を基準にずらし、`absolute`は通常の流れから外して配置する。基本例では親に`position: relative`を付けて、子の配置の基準を作る。

`display`로 표시 방식이나 배치를 바꾼다. 위치를 지정하는 `position`에서 `relative`는 원래 위치를 기준으로 이동하고, `absolute`는 일반적인 배치 흐름에서 빠져나와 배치된다. 기본 예제에서는 부모에 `position: relative`를 주어 자식의 배치 기준을 만든다.

`fixed`は画面に固定する配置、`sticky`はスクロールに応じて指定位置にとどまる配置として整理しておく。`float`は画像などの周りに文章を回り込ませるときに使い、解除には`clear`を使う。

`fixed`는 화면에 고정하는 배치, `sticky`는 스크롤에 따라 지정한 위치에 머무르는 배치로 구분해 둔다. `float`는 이미지 등 주변으로 글을 흐르게 할 때 사용하며 해제할 때는 `clear`를 쓴다.

Flexboxでは、一方向に並べることを基本に考える。`flex-direction`で主軸を決め、`justify-content`で主軸方向、`align-items`で交差軸方向をそろえる。縦に並べるときと横に並べるときで、軸の向きが変わる点を覚えておきたい。

Flexbox는 한 방향으로 나열하는 것을 기본으로 생각한다. `flex-direction`으로 주축을 정하고 `justify-content`로 주축 방향, `align-items`로 교차축 방향을 정렬한다. 세로 배치와 가로 배치에서 축 방향이 바뀌는 점을 기억해 두려고 한다.

```css
.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}
```

`flex-wrap`は折り返し、`gap`は要素同士の間隔。行と列を組み合わせて並べるならGridを使える。

`flex-wrap`은 줄바꿈, `gap`은 요소 사이의 간격이다. 행과 열을 함께 사용해 배치할 때는 Grid를 쓸 수 있다.

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}
```

この例は3列に分ける指定。`repeat()`で繰り返し、`fr`で利用可能な余白を分配する。FlexboxとGridはどちらか一つだけを使うものではなく、並べたい内容に合わせて考える。

위 예제는 세 열로 나누는 지정이다. `repeat()`는 반복하고 `fr`은 사용 가능한 여유 공간을 나눈다. Flexbox와 Grid 중 하나만 써야 하는 것은 아니고 배치할 내용에 맞게 생각한다.

## 画面の幅に合わせる

パソコンで見たときだけでなく、狭い画面でも読めるようにしたい。画面の幅に応じてCSSを変えるにはメディアクエリーを使う。

컴퓨터 화면에서만 괜찮은 것이 아니라 좁은 화면에서도 읽을 수 있어야 한다. 화면 너비에 따라 CSS를 바꿀 때는 미디어 쿼리를 사용한다.

```css
@media (max-width: 600px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
```

先ほどの3列を、600px以下では1列に変える例になる。HTMLの`head`にはviewportの設定も入れておく。

앞의 세 열 배치를 600px 이하에서는 한 열로 바꾸는 예제다. HTML의 `head`에는 viewport 설정도 넣는다.

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

単位では、`rem`はルート要素の文字サイズが基準。`em`は使う場所によって基準が変わり、`font-size`では親の文字サイズが基準になる。画像は`max-width: 100%`と`height: auto`で親の幅を超えないようにできる。大きさの決まった枠に収める場合は`object-fit`も使える。

단위에서 `rem`은 루트 요소의 글자 크기가 기준이다. `em`은 쓰는 곳에 따라 기준이 달라지고 `font-size`에서는 부모의 글자 크기가 기준이다. 이미지에 `max-width: 100%`와 `height: auto`를 주면 부모 너비를 넘지 않도록 할 수 있다. 정해진 크기의 영역에 넣을 때는 `object-fit`도 사용한다.

## 細かい指定と動き

`.card p`はcardの中の子孫の段落、`.card > p`は直接の子の段落を選ぶ。兄弟を選ぶ`+`や`~`、属性を指定して選ぶセレクターもある。

`.card p`는 card 안의 자손 문단, `.card > p`는 바로 아래 자식 문단을 선택한다. 형제를 선택하는 `+`, `~`와 속성으로 고르는 선택자도 있다.

`:hover`はマウスを重ねた状態、`:nth-child()`は並び順などで選ぶ疑似クラス。`::before`や`::after`は疑似要素で、装飾を足すときなどに使う。

`:hover`는 마우스를 올린 상태, `:nth-child()`는 순서 등으로 선택하는 가상 클래스다. `::before`, `::after`는 가상 요소로 장식 등을 추가할 때 사용한다.

CSSの関数には計算する`calc()`、値を比較する`min()`や`max()`、最小値・目安・最大値を指定する`clamp()`もある。`filter`ではぼかしや明るさなどを変えられる。

CSS 함수에는 계산하는 `calc()`, 값을 비교하는 `min()`, `max()`, 최솟값·선호값·최댓값을 지정하는 `clamp()`도 있다. `filter`는 흐림이나 밝기 등을 바꿀 때 사용한다.

動きを付けるところでは、`transform`、`transition`、`animation`を分けて覚える。`transform`は移動・回転・拡大縮小などの変形。`transition`は状態が変わったときの変化を滑らかにする。

움직임을 넣는 부분에서는 `transform`, `transition`, `animation`을 구분한다. `transform`은 이동·회전·확대 및 축소 같은 변형이다. `transition`은 상태가 바뀔 때의 변화를 부드럽게 만든다.

```css
button {
  transition: transform 0.2s ease;
}

button:hover,
button:focus-visible {
  transform: translateY(-2px);
}
```

この例では、ボタンにマウスを重ねたりキーボードでフォーカスしたりすると、少し上に動く。`transform`で動かしても、周囲の要素の通常の配置が組み直されるわけではない。

위 예제는 버튼에 마우스를 올리거나 키보드로 포커스하면 조금 위로 움직이게 한다. `transform`으로 움직여도 주변 요소의 일반 배치가 다시 구성되는 것은 아니다.

`animation`では`@keyframes`で途中の変化も指定できる。移動の`translate()`、回転の`rotate()`、拡大縮小の`scale()`、傾斜の`skew()`と、3Dの見え方に関わる`perspective`も整理しておく。

`animation`은 `@keyframes`로 중간 변화도 지정할 수 있다. 이동하는 `translate()`, 회전하는 `rotate()`, 확대·축소하는 `scale()`, 기울이는 `skew()`와 3D 원근감에 관련된 `perspective`도 정리해 둔다.

```css
.marker {
  animation: slide 1s ease-in-out;
}

@keyframes slide {
  from { transform: translateX(0); }
  to { transform: translateX(24px); }
}
```

## 覚えておきたいこと

HTMLは内容と構造、CSSは見た目と配置、と分けて考える。CSSの名前を一度に全部覚えるより、まずは余白や並び方を変えて、どこが変わるのかを確認していきたい。

特にpaddingとmargin、Flexboxの軸、画面が狭くなったときの配置は、コードと表示を見比べながら復習しようと思う。変更したら保存して、ブラウザーを再読み込みするところも忘れないようにしたい。

HTML은 내용과 구조, CSS는 모양과 배치로 나누어 생각한다. CSS 이름을 한 번에 외우기보다 여백이나 배치를 바꾸면서 어느 부분이 달라지는지 확인하려고 한다.

특히 padding과 margin, Flexbox의 축, 화면이 좁아졌을 때의 배치는 코드와 화면을 비교하면서 복습하려고 한다. 수정한 다음 저장하고 브라우저를 새로고침하는 것도 잊지 않으려고 한다.
