# Frontend Study

授業で学んだHTMLを復習するための学習用リポジトリです。
授業は韓国語で受けていたため、コード内の文章とコメントは韓国語にしています。

## このリポジトリについて

保存していた授業ファイルの内容をもとに、短い復習用の例を作成しました。
教材の原本や解答ファイル一式を転載したものではありません。
公開用のコードとREADMEの整理にはAIの支援を使用しています。
実際に確認した結果や、自分で変更した内容は、確認後に追記していきます。

## 学習内容

| フォルダー | 内容 |
|---|---|
| [01-basic-structure](html/01-basic-structure/index.html) | HTMLの基本構造、headとbody |
| [02-semantic-layout](html/02-semantic-layout/index.html) | header、nav、main、section、footer |
| [03-text-and-lists](html/03-text-and-lists/index.html) | 見出し、段落、強調、リスト |

| [05-tables](html/05-tables/index.html) | 表の構造、rowspan、colspan |
| [06-form-basics](html/06-form-basics/index.html) | label、id、name、選択項目 |
| [07-validation-and-buttons](html/07-validation-and-buttons/index.html) | required、readonly、disabled、ボタン |

## 実行方法

リポジトリをダウンロードし、各フォルダーの`index.html`をブラウザーで開きます。
リンクと画像の例は、関連ファイルも同じ構成で保存してください。
インストールやビルドは不要です。

フォームは学習用です。送信後は同じページへ移動し、GETの入力項目がURLに表示されます。
情報の保存、メール送信、会員登録などのサーバー機能はありません。
