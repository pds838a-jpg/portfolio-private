CSSの余白には`padding`と`margin`がある。どちらも空間を作る指定だけれど、空間ができる場所が違う。要素の幅を考えるときには`box-sizing`も関係するので、一緒に整理してみようと思う。

CSS에서 여백을 지정할 때는 `padding`과 `margin`을 사용한다. 둘 다 공간을 만들지만 공간이 생기는 위치가 다르다. 요소의 너비를 생각할 때는 `box-sizing`도 관련되므로 함께 정리해 보려고 한다.

## 箱の内側と外側

要素の箱は、内側から次の順番で考える。

요소의 박스는 안쪽부터 다음 순서로 생각하면 된다.

```text
内容 → padding → border → margin
내용 → 안쪽 여백 → 테두리 → 바깥쪽 여백
```

`padding`は内容と枠線の間にある余白。`margin`は枠線の外側にある余白になる。背景色は通常paddingの部分にも表示されるが、marginの部分には表示されない。

`padding`은 내용과 테두리 사이의 여백이다. `margin`은 테두리 바깥의 여백이다. 배경색은 일반적으로 padding 영역에도 표시되지만 margin 영역에는 표시되지 않는다.

例えばカードを作るなら、文字が枠に近すぎないようにするのがpadding、カードと周りの要素との距離を取るのがmargin、と考えると分かりやすい。

카드를 만든다고 생각하면 글자가 테두리에 너무 붙지 않게 하는 것은 padding, 카드와 주변 요소 사이의 거리를 만드는 것은 margin이라고 이해할 수 있다.

## widthだけでは全体の幅が決まらない

次のコードでは、内容の幅を200pxにしている。

다음 코드는 내용의 너비를 200px로 지정한다.

```html
<div class="card">
  <p>CSSの余白を復習しています。</p>
</div>
```

```css
.card {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 2px solid #555;
  margin: 16px;
  background-color: #eef5ff;
}

.card p {
  margin: 0;
}
```

`content-box`では、`width`は内容部分の幅になる。paddingとborderは、その幅の外側に追加される。

`content-box`에서는 `width`가 내용 영역의 너비가 된다. padding과 border는 그 너비 바깥에 추가된다.

```text
200 + 20 × 2 + 2 × 2 = 244px
```

つまり、枠線まで含めた幅は244pxになる。左右のmarginはさらに外側にあり、この244pxには含まれていない。

즉 테두리까지 포함한 너비는 244px이다. 좌우 margin은 그보다 바깥에 있으며 244px에 포함되지 않는다.

`p`にも標準の余白があるため、この例では`margin: 0`にしている。カード自身の余白を考えるときは、内側の要素に付いている余白も確認したい。

`p`에도 기본 여백이 있으므로 이 예제에서는 `margin: 0`으로 지정했다. 카드의 여백을 볼 때는 내부 요소에 설정된 여백도 함께 확인해야 한다.

## border-boxに変えるとどうなる？

先ほどのカードに、次の指定を加える。

앞의 카드에 다음 지정을 적용한다.

```css
.card {
  box-sizing: border-box;
}
```

今度は200pxの中にpaddingとborderが含まれる。左右のpaddingとborderを引くと、内容部分の幅は156pxになる。

이제 200px 안에 padding과 border가 포함된다. 좌우 padding과 border를 빼면 내용 영역의 너비는 156px이다.

```text
200 − 20 × 2 − 2 × 2 = 156px
```

`border-box`にすると余白がなくなるわけではない。指定した幅の中で、内容・padding・borderに使う場所が分かれる。

`border-box`로 바꾼다고 여백이 없어지는 것은 아니다. 지정한 너비 안에서 내용·padding·border가 사용할 공간이 나누어진다.

## 覚えておきたいこと

文字と枠の間を広げたいならpadding、箱と周囲の距離を変えたいならmarginを考える。指定した幅より箱が大きく見えるときは、`box-sizing`とpadding、borderを確認する。

글자와 테두리 사이를 넓히고 싶으면 padding, 박스와 주변 사이의 거리를 바꾸고 싶으면 margin을 생각한다. 지정한 너비보다 박스가 커 보이면 `box-sizing`, padding, border를 확인한다.

まずは同じコードで`content-box`と`border-box`を切り替えて、開発者ツールのボックスモデル表示を見比べてみたい。

우선 같은 코드에서 `content-box`와 `border-box`를 바꾸고 개발자 도구의 박스 모델 표시를 비교해 보려고 한다.
